# Bundled design skills

Source: https://github.com/jakubkrehel/skills
Revision: 267330e1adfc66a718fb65fa6918c1f06d0a689e
License: MIT, see LICENSE.

The seven better-* skills and their Markdown references are vendored with only
redundant blank lines at the end of files removed.
Dezin supplies them as read-only, checksum-verified context for design generation
and screenshot review. No network request or global skill installation is needed.
Project direction and the confined output contract take precedence over these
design references.
